# FlowBiz Sign · דף חתימות

ממשק עברי לחתימה דיגיטלית על מסמכים — העלאה, מיקום שדות חתימה/חותמת/תאריך/טקסט, יצירת קישור לחתימת הצד השני, והורדת PDF חתום.

## הפעלה מקומית

זהו אתר סטטי ללא תהליך build. אפשר לפתוח את `index.html` ישירות בדפדפן, או להריץ שרת סטטי:

```bash
npx serve .
# או
python -m http.server 8000
```

## פריסה ב-Vercel

```bash
vercel --prod
```

## מבנה הפרוייקט

- `index.html` / `דף חתימות.html` — נקודת הכניסה
- `app.jsx` — אפליקציה ראשית, ספריית מסמכים, ניתוב קישורי שיתוף
- `editor.jsx` — עורך המסמכים (תצוגת בעלים)
- `client-view.jsx` — תצוגת לקוח מצומצמת לחתימה בלבד
- `signature-pad.jsx` — לוח חתימה (ציור / הקלדה)
- `documents.jsx` — תבניות דמו
- `components.jsx` — אייקונים, Modal, Toast
- `styles.css` — עיצוב מלא
- `assets/` — לוגו וחותמת

## תצוגות

- **בעלים** (`#` או ברירת מחדל): ספרייה + עורך מלא
- **לקוח** (`#share=<token>`): תצוגה נעולה — צפייה במסמך + חתימה בלבד, ללא סרגלי כלים, ללא עריכת מבנה
