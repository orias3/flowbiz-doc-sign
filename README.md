# FlowBiz Sign · דף חתימות

ממשק עברי לחתימה דיגיטלית על מסמכים — העלאה, מיקום שדות חתימה/חותמת/תאריך/טקסט, קישור חתימה לצד השני (או לכמה חותמים לפי סדר), audit trail מלא, והורדת PDF חתום.

## הפעלה מקומית

```bash
npm install
npm run dev        # Vite dev server (ללא ה-API)
```

להרצה מלאה כולל ה-API (מדמה את Vercel):

```bash
npm run build
node scripts/dev-server.mjs   # http://localhost:4173
```

בדיקות:

```bash
npm test
```

## פריסה ב-Vercel

```bash
vercel --prod
```

הבילד מוגדר ב-`vercel.json` (Vite → `dist/`). ה-API רץ כ-Vercel Functions מתוך `api/`.

### משתני סביבה (ראו `.env.example`)

| משתנה | תפקיד |
|---|---|
| `ADMIN_EMAILS`, `ADMIN_PASSWORD` | כניסת מנהלים — **חובה להגדיר ולהחליף את הסיסמה הישנה** |
| `STATE_SECRET` | הצפנת state המנהלים ב-Blob (AES-256-GCM) |
| `GMAIL_USER`, `GMAIL_APP_PASSWORD`, `EMAIL_FROM` | שליחת מיילים (הזמנות, עותקים חתומים, תזכורות) |
| `CRON_SECRET` | הגנה על ה-cron של התזכורות |

## מבנה הפרוייקט

- `index.html` — נקודת כניסה (Vite)
- `src/main.jsx` + `src/globals.js` — bootstrap וטעינת ספריות (React, pdf.js, jsPDF…)
- `src/app.jsx` — אפליקציה ראשית, ספריית מסמכים, סנכרון בין מנהלים, ניתוב קישורי שיתוף
- `src/editor.jsx` — עורך המסמכים (תצוגת בעלים) + ניהול חותמים
- `src/client-view.jsx` — תצוגת לקוח מצומצמת לחתימה בלבד
- `src/signature-pad.jsx` — לוח חתימה (ציור / הקלדה)
- `src/documents.jsx` — תבניות
- `src/components.jsx` — אייקונים, Modal, Toast
- `styles.css` — עיצוב מלא
- `api/share.js` — יצירה/קריאה/חתימה של מסמכים משותפים
- `api/admin/state.js` — state משותף למנהלים (מיזוג לפי id + גיבויים + הצפנה)
- `api/cron/reminders.js` — תזכורות אוטומטיות לחותמים (cron יומי)
- `lib/` — לוגיקה משותפת (merge, הצפנה, מיילים) — מכוסה בבדיקות `tests/`

## אבטחה — עקרונות

- **אימות מנהלים בשרת בלבד** (`ADMIN_EMAILS`/`ADMIN_PASSWORD`); שום סוד לא נשלח לדפדפן.
- **מפתח בעלים לכל שיתוף**: עריכת מסמך משותף ושליחת מיילים דורשות `ownerKey` שנוצר ביצירת הקישור. מסמכים ישנים (לפני העדכון) ממשיכים לעבוד.
- **זרימת חתימה מוגבלת**: חותם יכול רק למלא את השדות שלו ולהוסיף את חותמת הסיום — לא לשנות תוכן, מבנה או מיילים.
- **Audit trail**: כל חתימה נרשמת עם זמן שרת, IP, דפדפן ו-hash של תוכן המסמך.
- **הצפנת state**: עם `STATE_SECRET`, ה-state המרוכז מוצפן ב-Blob.
- **הגבלת קצב** לשליחת מיילים (5 לשעה למסמך) ו-escaping מלא בתבניות המייל.

## תצוגות

- **בעלים** (ברירת מחדל): ספרייה + עורך מלא — מאחורי התחברות
- **לקוח** (`/s/<id>` או `/s/<id>?sg=<signer>`): תצוגה נעולה — צפייה + חתימה בלבד
- **ריבוי חותמים**: כל חותם מקבל קישור אישי; החתימה לפי סדר, הזמנות ותזכורות במייל אוטומטיות
